# Tandem Propeller

Parent category: **Propeller Aerodynamics and Distributed Propulsion**

## Important Findings

These papers show how tandem propellers interact when they are vertically offset, positively staggered, or closely spaced. The main finding is that tandem rotors do not behave like two independent propellers; geometry changes the wake interaction and therefore the net performance.

## Value

The value is in design guidance for distributed propulsion. The folder identifies the spacing, offset, and modeling choices that matter when multiple rotors are used together in compact configurations.

## Key Takeaways

Tandem propellers are a coupled aerodynamic system. Linear superposition can be useful, but only after the geometry and overlap conditions are understood well enough to know where that approximation will work.

## Papers

- **Vertically Offset Overlapping Propellers in Tandem Configuration** (`cai-et-al-2023-vertically-offset-overlapping-propellers-in-tandem-configuration.pdf`)
  Establishes the baseline tandem interaction problem and shows how vertical offset changes the coupled wake and performance.
- **Investigation of Positively Staggered Vertically Offset Propellers in Tandem** (`cai-et-al-2024-investigation-of-positively-staggered-vertically-offset-propellers-in-tandem.pdf`)
  Refines the tandem problem by examining stagger and offset together, which is directly relevant to compact multi-rotor layouts.
- **Prediction of the Tandem Propeller Performance Using Linear Superposition Method** (`cai-gunasekaran-2025-prediction-of-the-tandem-propeller-performance-using-linear-superposition-method.pdf`)
  Tests whether tandem performance can be predicted well enough for design work using a simplified superposition approach.
