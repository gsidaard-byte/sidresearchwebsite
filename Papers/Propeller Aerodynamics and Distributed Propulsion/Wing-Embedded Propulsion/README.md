# Wing-Embedded Propulsion

Parent category: **Propeller Aerodynamics and Distributed Propulsion**

## Important Findings

These papers study configurations where the wing and propeller must be treated as one aerodynamic system. The key result is that embedding, tilt, incidence, and spanwise location all change not just the propeller loading but the wing-propeller interaction itself.

## Value

The value is direct design guidance for blown-wing and propeller-in-wing concepts. The papers help determine when a simple additive model is adequate and when the coupling is strong enough that the full installation must be considered.

## Key Takeaways

Wing-embedded propulsion is fundamentally an interaction problem. Rotor placement, inlet shape, and incidence setting can be as important as the propeller hardware itself for thrust vectoring and overall performance.

## Papers

- **On the Linear Superposition of Wing and Propeller Performance in a Wing Embedded Propeller System** (`cai-et-al-2024-on-the-linear-superposition-of-wing-and-propeller-performance-in-a-wing-embedded-propeller-system.pdf`)
  Tests whether wing and propeller effects can be combined simply or whether the embedded configuration produces stronger nonlinear coupling.
- **Propeller and Propeller-in-Wing Thrust Vectoring** (`culpepper-et-al-2021-propeller-and-propeller-in-wing-thrust-vectoring.pdf`)
  Shows how embedding changes thrust-vectoring behavior relative to a standalone propeller.
- **Effect of Forward Propeller Tilt and Inlet Shape in Propeller-in-Wing Thrust Vectoring** (`culpepper-et-al-2022-effect-of-forward-propeller-tilt-and-inlet-shape-in-propeller-in-wing-thrust-vectoring.pdf`)
  Highlights the geometric variables that most strongly affect thrust-vectoring effectiveness.
- **Effect of Propeller Incidence Angle on Wing Embedded Propeller Configuration in Forward Flight** (`gogidze-et-al-2023-effect-of-propeller-incidence-angle-on-wing-embedded-propeller-configuration-in-forward-flight.pdf`)
  Extends the wing-embedded study into forward flight, where incidence angle becomes a key driver of performance and wake structure.
