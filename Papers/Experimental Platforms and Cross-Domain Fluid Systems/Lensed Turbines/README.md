# Lensed Turbines

Parent category: **Experimental Platforms and Cross-Domain Fluid Systems**

## Important Findings

These papers transfer aerodynamic tools into wind-energy settings, showing that wake interactions and proximity effects can be quantified with the same experimental mindset used for wings and propellers.

## Value

Their value is generalization: aircraft-flow methods remain useful in adjacent fluid systems when the goal is to understand how wakes bias power, mixing, and losses.

## Key Takeaways

Aerodynamic wake physics is portable across domains, and the same measurement logic can reveal performance mechanisms in very different geometries.

## Papers

- **Aerodynamic Interactions of Wind Lenses at Close Proximities** (`energies-15-04622.pdf`)
  Journal paper on wind-lens interaction physics in a wind-energy setting. It shows how spacing changes wake coupling and performance.
- **Performance and Proximity Investigations on Small Scale Lensed Turbines** (`novotny-gunasekaran-2020-performance-and-proximity-investigations-on-small-scale-lensed-turbines.pdf`)
  Cross-domain rotor-flow study focused on wind-energy lens effects rather than aircraft propulsion. The main contribution is a small-scale performance map for lensed turbines.
- **Investigation into Wake Interactions of Wind Lenses at Close Proximities** (`peyton-gunasekaran-2022-investigation-into-wake-interactions-of-wind-lenses-at-close-proximities.pdf`)
  Cross-domain wind-energy application focused on wake interactions between lens profiles. It extends the same wake-aware logic to proximity-sensitive arrangements.
